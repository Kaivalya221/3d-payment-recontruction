# 3D Pavement Reconstruction Website

## Overview
This project focuses on the innovative use of smartphone videos and structure-from-motion technology for 3D pavement reconstruction. The website serves as a comprehensive resource, showcasing advanced techniques, methodologies, tools, case studies, and potential applications in the field.

## Project Structure
The project is organized as follows:

```
3d-pavement-reconstruction-website
├── public
│   └── index.html          # Main HTML entry point
├── src
│   ├── assets              # Static assets (images, videos, etc.)
│   ├── components          # Reusable components (Header, Footer, Navbar, etc.)
│   ├── pages               # Different pages of the website (Home, Techniques, etc.)
│   ├── styles              # CSS styles for the website
│   ├── utils               # Utility functions
│   └── App.tsx             # Main application component
├── package.json            # npm configuration file
├── tsconfig.json           # TypeScript configuration file
└── README.md               # Project documentation
```

## Features
- **Advanced Techniques**: Detailed descriptions of the techniques used in 3D pavement reconstruction.
- **Methodology**: An outline of the research methodology employed in the project.
- **Tools**: A comprehensive list of tools utilized for 3D reconstruction from smartphone videos.
- **Case Studies**: Showcases of various case studies demonstrating the application of the technology.
- **Applications**: Discussion on potential applications of 3D pavement reconstruction in various fields.
- **Contact**: A contact form for inquiries and feedback.

## Getting Started
To set up the project locally, follow these steps:

1. **Clone the repository**:
   ```
   git clone <repository-url>
   cd 3d-pavement-reconstruction-website
   ```

2. **Install dependencies**:
   ```
   npm install
   ```

3. **Run the application**:
   ```
   npm start
   ```

The application will be available at `http://localhost:3000`.
